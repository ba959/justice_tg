# 🛡️ Justice Bot — Telegram

**Белый хакер в кармане.** Бот для защиты от доксинга, сватинга и ДДоС-угроз: собирает доказательства с SHA-256, ищет нарушителя по открытым данным, проверяет уязвимости и оформляет жалобы по официальным каналам.

> ⚖️ Только легальные методы: публичные реестры, официальные API, собственные данные пользователя.

## Возможности

| Модуль | Команды | Что делает |
|---|---|---|
| 🔎 OSINT | `/username`, `/ip`, `/email`, `/domain`, `/dns` | Поиск по открытым данным |
| 🕵️ Досье | `/dossier`, `/trace`, `/scan` | Карточка нарушителя + риск-оценка |
| 🔐 Пароли | `/pass`, `/strength` | Проверка по утечкам + энтропия |
| 🔒 Сайты | `/ssl`, `/seccheck`, `/urlcheck`, `/audit` | Фишинг, сертификаты, заголовки |
| 🦠 Файлы | `/hashcheck` | Проверка хеша в антивирусной базе |
| 📧 Почта | `/dmarc`, `/validate` | SPF/DKIM/DMARC, disposable-сервисы |
| 🛡️ Watchlist | `/watch add/remove/list/check` | Мониторинг утечек своих email |
| 📸 Доказательства | `/evidence`, `/export` | Кейсы с SHA-256 для полиции |
| 🚨 Жалобы | `/report`, `/report links` | Официальные ссылки репортов |
| 👁 Мониторинг | `/monitor` | Авто-фиксация угроз в чатах |
| 📊 Логи | `/logscan` | Поиск DDoS в access.log своего сервера |

## Быстрый старт

1. Скопируй настройки: `config.example.py` → `config.py`, впиши токен от [@BotFather](https://t.me/BotFather)
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запусти:
   ```bash
   python bot.py
   ```
